# Local FSAE RAG Pipeline dependencies
#
# Install PyTorch separately first with the CUDA wheel that matches the machine:
#   pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
#
# The torch/torchvision pins below are for the CPU build; the --index-url above
# overrides them with the CUDA-enabled wheel of the same version. If you change
# the pin, update the --index-url tag to match.
#
# Then install the rest:
#   pip install -r requirements.txt
#
# Pins use ~= (compatible-release): patch updates are allowed, but minor/major
# jumps are blocked. This balances reproducibility with security fixes.
