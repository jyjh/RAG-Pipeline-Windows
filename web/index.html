New User Guide

Use this app to turn trusted local PDFs into a searchable engineering knowledge base, review extracted content, and ask source-cited questions from the local index.

Core Workflow

  1. Add PDFs On the Documents tab, upload team reports, textbooks, notes, papers, or standards and choose a reliability group for each PDF. You can also drop a .zip of PDFs — subfolders are flattened automatically.
  2. Wait for jobs The Documents tab tracks every background job with live progress. A banner at the top of any tab shows the active job; ingestion extracts Markdown and assets, and indexing builds the retrieval database in the background.
  3. Review sources On the Library tab, tag highlighted ungrouped PDFs, check quality badges, trust status, downloads, and extracted index rows before relying on answers.
  4. Ask questions Use the Ask tab for evidence-backed answers, then inspect Sources and Tool results.

Intended Use

  • Keep FSAE knowledge transfer local and reproducible across uploaded source documents.
  • Prefer reviewed, approved sources for design decisions, calculations, and team documentation.
  • Use web search only as supporting context when local PDFs are incomplete or outdated.

Review Checklist

  • Confirm each PDF has useful extracted text and nonzero chunks.
  • Tag ungrouped PDFs as Official, Student Research, or Unofficial so retrieval ranking can weight sources correctly. Use "Auto-tag ungrouped" for a first LLM pass, then review the Auto-tagged rows; manual tags always override.
  • Open cited pages or downloads when an answer affects engineering decisions.
  • Flag stale or rejected sources so future users see the risk before relying on them.
  • Re-run a single PDF when OCR, figures, formulas, or source metadata look wrong.

Operating Notes

  • Long ingestion and indexing jobs run in the background; chat can still use the last published index.
  • Index edits are disabled while indexing is active to avoid writing into a changing database.
  • Administrators manage API keys and index maintenance (backup, restore, rebuild) from the Admin tab.
  • Saved chats live in this browser only and are useful for recurring investigation threads.
